## 5. NetworkAnalyzer Class Initialization

```python
class NetworkAnalyzer:
    def __init__(self, pcap_file, protocol_filter=None):
        self.pcap_file = pcap_file
        self.protocol_filter = protocol_filter
        self.stats = {
            'total_packets': 0,
            'src_ips': set(),
            'dst_ips': set(),
            'countries': set(),
            'destinations': defaultdict(int),
            'protocol_counts': defaultdict(int),
            'port_services': defaultdict(int)
        }
        self.connections = []
        try:
            self.my_geo = gi.record_by_name(MY_PUBLIC_IP)
            if not self.my_geo:
                self.my_geo = {'latitude': 12.9716, 'longitude': 77.5946,
                               'city': 'Bangalore', 'country_name': 'India'}
        except:
            self.my_geo = {'latitude': 12.9716, 'longitude': 77.5946,
                           'city': 'Bangalore', 'country_name': 'India'}
```



### 1. Inputs \& Filters

- **`pcap_file`:** Path to the packet capture file for analysis. Typically generated by Wireshark.
- **`protocol_filter`:** Optional argument. Accepts protocol names (e.g., `'TCP'`, `'UDP'`, `'HTTP'`) that restrict analysis to specific types. If `None`, the class analyzes all protocols present in the file.


### 2. Statistics Initialization (`stats` Dictionary)

This dictionary is designed for efficient accumulation of diverse metrics:

- **`total_packets`:** Counter for processed packets.
- **`src_ips`:** Set of all unique source IP addresses found.
- **`dst_ips`:** Set of all unique destination IPs.
- **`countries`:** Tracks all unique countries associated with traffic endpoints (resolved via geo-IP lookup).
- **`destinations`:** Counts how many packets were sent to each destination IP (uses `defaultdict(int)` for convenient counting).
- **`protocol_counts`:** Tracks the number of packets for each protocol.
- **`port_services`:** Maps destination ports to packet counts, useful for identifying active network services.


### 3. Connections List

- **`connections`:** List initially empty. As packets are parsed, records are appended detailing each connection—could include timestamp, source/destination IP, ports, protocol, and geo-IP locations.


### 4. Geo-IP Lookup Setup (`my_geo`)

- **Purpose:** Obtains the user's (the machine running analysis) public IP geolocation using a geo-IP library (such as GeoLiteCity).
- **Fallback Logic:** If geo-IP lookup fails (or doesn't return a valid result), defaults to hardcoded location data for Bangalore, India. This guarantees consistent mapping/visualization output even if geo-location lookup for the host fails.



## Why These Components Matter

- **Efficient Tracking:** Sets and defaultdicts are ideal for scalable metric accumulation, even with large data.
- **Targeted Filtering:** Allows users to concentrate analysis on traffic that is most relevant (e.g., only TCP flows, or only HTTP requests).
- **Location Enrichment:** Geo-IP lookup adds physical context to network topology, making map-based trend analysis and anomaly detection possible.
- **Robustness:** Exception handling and fallback defaults prevent interruption due to data issues.

## 6. Service Identification by IP or Port

```python
def identify_service(self, ip, port):
    try:
        hostname = socket.gethostbyaddr(ip)[^0].lower()
        for domain, service in DOMAIN_SERVICES.items():
            if domain in hostname:
                return service
    except:
        pass
    for service, (_, ports) in PROTOCOL_COLORS.items():
        if service != 'DEFAULT' and port in ports:
            return service
    return 'Unknown'
```

- Tries to resolve the IP address to a hostname.
- Checks if any known domain keyword is in the hostname, returns mapped service name if so.
- If DNS resolution fails, it falls back to mapping based on well-known port numbers.
- Returns `'Unknown'` if no match found.

## 8. Packet Capture File Analysis

```python
def analyze_pcap(self):
    start_time = time.time()
    with open(self.pcap_file, 'rb') as f:
        pcap = dpkt.pcap.Reader(f)
        for ts, buf in pcap:
            self.stats['total_packets'] += 1
            try:
                eth = dpkt.ethernet.Ethernet(buf)
                if not isinstance(eth.data, dpkt.ip.IP):
                    continue
                ip = eth.data
                src = socket.inet_ntoa(ip.src)
                dst = socket.inet_ntoa(ip.dst)

                # Filter by protocol if specified
                protocol = self.get_protocol_name(ip)
                if self.protocol_filter and protocol.lower() != self.protocol_filter.lower():
                    continue
                self.stats['protocol_counts'][protocol] += 1

                # Extract ports for TCP/UDP
                src_port = dst_port = 0
                if isinstance(ip.data, (dpkt.tcp.TCP, dpkt.udp.UDP)):
                    src_port = ip.data.sport
                    dst_port = ip.data.dport
                self.stats['port_services'][dst_port] += 1

                # Update IP stats
                self.stats['src_ips'].add(src)
                self.stats['dst_ips'].add(dst)
                self.stats['destinations'][dst] += 1

                # Get destination geo info
                try:
                    dst_geo = gi.record_by_name(dst)
                    if dst_geo:
                        country = dst_geo.get('country_name', 'Unknown')
                        self.stats['countries'].add(country)

                        service = self.identify_service(dst, dst_port)

                        self.connections.append({
                            'timestamp': datetime.fromtimestamp(ts).strftime('%Y-%m-%d %H:%M:%S'),
                            'src': src,
                            'dst': dst,
                            'src_port': src_port,
                            'dst_port': dst_port,
                            'protocol': protocol,
                            'service': service,
                            'country': country,
                            'city': dst_geo.get('city', 'Unknown'),
                            'lat': dst_geo['latitude'],
                            'lon': dst_geo['longitude']
                        })
                except:
                    pass
            except:
                continue
    self.stats['processing_time'] = time.time() - start_time
    return self.connections
```




## Workflow Overview

1. **Initialization \& Timing**: Measures analysis speed and efficiency, useful for reporting and optimization.
2. **File Handling**: Safely opens the PCAP file in binary mode and uses `dpkt.pcap.Reader` to iterate through packets sequentially.[^1][^6][^7]
3. **Packet Loop**: For each packet, decodes Ethernet frame, checks for IP traffic, and processes based on protocol and user filters.
4. **Statistics Collection**: Updates metrics for packets, IPs, protocols, ports, and destinations.
5. **Geo-IP Lookup**: Resolves destination IPs to country, city, and coordinates using a geo-IP DB.
6. **Connections List**: Creates a summary record for each packet flow with timestamp, networking/data, and enrichment.
7. **Processing Time**: Records entire analysis duration for performance tracking.
8. **Returns**: Delivers connection summaries for visualization or reporting.



## Step-By-Step Functionality

### 1. Start Timer

- Measures processing speed (important for scaling, dashboard reporting).


### 2. Open \& Read PCAP File

- Uses Python's binary file handling (`'rb'`)
- `dpkt.pcap.Reader` parses the PCAP into packet objects, each with timestamp and payload.


### 3. Loop Over Packets

- **Increment Total Packet Counter:** For each packet processed.
- **Try-Everything Block:** Robust error handling to skip problematic packets.
- **Ethernet Frame Decoding:** Only considers packets encapsulating IP traffic.
- **Extract Source/Destination IPs:** Using `socket.inet_ntoa`, converts raw bytes to dotted IP address.[^7][^1]


### 4. Protocol Filtering

- Uses custom `get_protocol_name` to identify protocols (e.g., TCP, UDP, ICMP).
- If user specified, keeps only matching protocol (case-insensitive).
- Increments per-protocol packet count for statistics.[^6]


### 5. Port Extraction \& Service Identification

- If TCP/UDP, extracts source and destination ports.
- Updates stats mapping for destination port (helpful for application/service analysis).


### 6. Update IP Address Stats

- Adds source and destination IPs to sets for count of unique endpoints.
- Counts packet occurrences per destination IP (for mapping and anomaly detection).


### 7. Geo-IP Enrichment

- Tries to resolve destination IP to physical location using geo-IP DB (e.g., GeoLiteCity).
- If found, extracts country, city, latitude, longitude, and attaches to the connection record.
- Also, infers application service from destination and port.
- Appends summary of traffic session: timestamped and fully annotated.


### 8. Error Handling

- Ignore packets failing decoding, missing geo-IP info, or causing parsing errors—keeps analysis robust.


### 9. Processing Time

- Calculates total duration for entire file analysis and stores for reporting.


### 10. Return Connection List

- Final output: a list of per-packet/session records with networking, time, and geo-location info (used for KML visualization and dashboard HTML reports).



## Why This Structure Matters

- **Scalability:** Handles very large PCAP files efficiently by streaming and filtering.
- **Robustness:** Recovers gracefully from malformed or unsupported packets (critical in real-world traffic).
- **Comprehensive Metrics:** Captures and combines network, service, and physical location information for advanced investigations and map-based analytics.
- **Extensibility:** Modular for adding more statistics, advanced filtering, or other protocol parsers if needed.

### 9. Protocol Detection Helper

```python
def get_protocol_name(self, ip):
    if isinstance(ip.data, dpkt.tcp.TCP):
        return 'TCP'
    elif isinstance(ip.data, dpkt.udp.UDP):
        return 'UDP'
    elif isinstance(ip.data, dpkt.icmp.ICMP):
        return 'ICMP'
    return 'Other'
```

- Determines protocol type by checking internal packet data type.
- Useful for protocol-based filtering and statistics.

### 10. Generating Human-Readable Analysis Reports

```python
def generate_statistics_report(self):
    report = f"""
{'='*60}
NETWORK TRAFFIC ANALYSIS REPORT
{'='*60}
SOURCE INFORMATION:
Your IP: {MY_PUBLIC_IP}
Location: {self.my_geo.get('city', 'Unknown')}, {self.my_geo.get('country_name', 'Unknown')}
OVERVIEW:
Total Packets Analyzed: {self.stats['total_packets']:,}
Unique Source IPs: {len(self.stats['src_ips'])}
Unique Destination IPs: {len(self.stats['dst_ips'])}
Countries Detected: {len(self.stats['countries'])}
Processing Time: {self.stats['processing_time']:.2f} seconds
PROTOCOL DISTRIBUTION:
"""
    for proto, count in sorted(self.stats['protocol_counts'].items(), key=lambda x: x[^1], reverse=True):
        report += f" {proto}: {count:,} packets\n"
    report += "\nTOP 10 DESTINATION IPs:\n"
    for ip, count in sorted(self.stats['destinations'].items(), key=lambda x: x[^1], reverse=True)[:10]:
        report += f" {ip}: {count} connections\n"
    report += "\nTOP SERVICES/PORTS:\n"
    for port, count in sorted(self.stats['port_services'].items(), key=lambda x: x[^1], reverse=True)[:10]:
        service = self.identify_service('', port)
        report += f" Port {port} ({service}): {count} connections\n"
    report += "\nCOUNTRIES DETECTED:\n"
    for country in sorted(self.stats['countries']):
        report += f" - {country}\n"
    report += f"\n{'='*60}\n"
    with open('traffic2_statistics.txt', 'w') as f:
        f.write(report)
    print(report)
    return report
```

- Creates a formatted multiline string report with:
    - Basic source info,
    - Total packets,
    - Unique IP counts,
    - Countries observed,
    - Protocol distribution,
    - Top destination IPs by number of connections,
    - Top ports with service names,
    - Countries observed in traffic.
- Writes this report to a file and prints it.
